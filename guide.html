FinanceSim 使用指南

一个从真实金融市场状态启动、能在本地独立运行、随模拟时间向未来自主演化的多市场金融世界。本指南带你从“装好能打开”到“懂得怎么玩、怎么玩出意思”。

1. 这是什么

FinanceSim 不是行情软件，而是一个“活的金融世界”：它以真实世界的股票 / 外汇 / 债券 / 指数 / 商品为初始资产，在本地用确定性随机引擎推演未来——价格随机游走、新闻不断生成、宏观缓慢演化、突发事件冲击市场、AI 交易员自动买卖。

它能在本地做什么：

  • 620+ 真实资产：股票约 455、债券 48、ETF 40、外汇 52、指数 25、商品若干（含原油 / 黄金 / 铜等）。
  • 12+ 核心引擎：市场、模拟时钟、撮合、交易、组合、风控、分析、事件、新闻、宏观、债券、外汇、AI 交易员、商品。
  • 实时行情流：WebSocket 每秒推送一次全市场报价，前端即时刷新。
  • 可真实交易：市价单 / 限价单，成交写库、组合同步、可跨重启保留。
  • 真实数据可开：联网后接入 CNBC 行情、ECB 外汇、FRED 宏观、RSS 新闻，全部免 key；断网自动回退合成数据。
一句话定位：把它当成你私人的、可随意快进 / 重来的“金融沙盒”——既能练交易、做压力测试，也能看一个虚拟世界经济如何随新闻与宏观起伏。

2. 三分钟跑起来

有两种方式。只想玩 → 走 Docker；想改代码 / 看日志 → 走源码开发模式。

方式 A：源码开发模式（前后端分离）

后端默认端口 8000，前端开发服务器（Vite）端口 5174，前端会自动把 /api 请求和 WebSocket 代理到后端。

# 1) 启动后端（FastAPI + uvicorn）
cd FinSim/backend
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000

# 2) 另开一个终端启动前端
cd FinSim/frontend
npm install        # 首次需要
npm run dev        # 默认 http://localhost:5174
环境提示：若系统 PATH 里没有 python / npm，用本机托管运行时的完整路径，例如 C:/Users/Administrator/.workbuddy/binaries/python/versions/3.13.12/python.exe 与对应的 node.exe。详见第 9 节排错。

方式 B：Docker 一键部署（推荐给只想玩的人）

镜像内已把前端静态产物挂到后端，一个容器、一个端口：浏览器直接开 http://localhost:8000/ 就是完整 SPA。

cd FinSim
docker build -t finsim .
docker run -p 8000:8000 finsim
# 浏览器访问 http://localhost:8000/

想带真实数据，启动时把后端 .env 挂进去（见第 3 节），或在 docker run 加 -e USE_EXTERNAL_DATA=True。

确认跑起来了

curl http://localhost:8000/health
# 返回 {"status":"healthy"} 即正常

3. 开启真实数据（可选但强烈推荐）

默认是 离线优先：所有数据用合成（SIMULATED）填充，断网也能玩。想要真实行情 / 宏观 / 新闻，只需打开一个开关。

步骤

  1. 在 FinSim/backend/ 下创建（或编辑）.env 文件（该文件已被 gitignore，不会进版本库）。
  2. 写入以下内容：
# backend/.env
USE_EXTERNAL_DATA=True
# 三个 key 留空即走免 key 公开源（CNBC / Frankfurter / FRED / RSS）
ALPHA_VANTAGE_API_KEY=
FRED_API_KEY=
NEWS_API_KEY=
  1. 重启后端。启动日志里会出现 “Headlines refreshed from external provider” 与宏观播种成功的提示。

三个真实数据源（全部免 key）：

数据类型真实来源标注
股票 / ETF / 指数行情CNBC 公开行情接口LIVE
外汇（ECB 主要货币对）Frankfurter（欧洲央行）LIVE
宏观经济（利率 / 通胀 / 失业）FRED（美联储圣路易斯）LIVE
新闻头条公开 RSS（WSJ / MarketWatch / CNBC）LIVE
为什么免 key 也能真？ 这些源是面向公众免费、无需令牌的公开接口（数据中心 IP 被个别源拦截时，代码会自动回退到合成数据，绝不会报错卡死）。

4. 先搞懂 4 个概念

① 世界（World）：一次模拟的独立沙盒，有自己的人口、资产、宏观与随机种子。默认世界 id=1。多世界互不干扰。

② 模拟时钟与倍速：时间是“模拟时间”，可快进。

  • X1 = 1 模拟秒 / 真实秒（实时地板，最慢也等于真时间流速）。
  • X10 / X100 / X1000 线性加速。默认 X100。
  • 关键设计：行情波动与倍速解耦——波动按“真实流逝的模拟秒数”缩放，所以快进 1000 倍 ≠ 失真 1000 倍，而是等价于让这个世界真实走过同样多的模拟时间。全真模拟

③ 资产（Asset）：股票 / 债券 / ETF / 外汇 / 指数 / 商品。每只都有板块、基本面、波动率、当前价。

④ 数据来源标注：界面里每条数据都会标明它是 LIVE/REAL、SIMULATED 还是 FALLBACK。这是平台的铁律之一——绝不用合成数据冒充真实功能。

5. 怎么玩：完整流程

跟着下面 8 步走一遍，你就真正“上手”了。

  1. 看总览：打开 Overview，看世界整体健康度、主要指数、今日要闻、组合快照。这是你的“驾驶舱”。
  2. 挑资产：进 Markets 或用顶部搜索 Search 找一只股票 / 外汇 / 债券 / 商品，点进 资产详情 能看到 K 线、基本面、相关新闻。
  3. 下第一单：进 Orders 选资产、填数量、选市价 / 限价，下单。成交后去 Portfolio 看持仓与盈亏。
  4. 让世界转起来：进 Simulation，点 Start，再调倍速（建议先 X100 感受，再 X1000 快进）。肉眼可见报价每秒跳动、K 线延伸。
  5. 读新闻与事件：News 里真实头条带来源徽标；Timeline 记录模拟过程中发生的突发事件及其价格冲击。
  6. 看 AI 对手盘：Bots 里预置了动量 / 均值回归 / 做市 / 宏观四类 AI 交易员，它们会自动买卖、制造市场活动。你也可以加自己的 bot。
  7. 接挑战：Challenges 给出带约束的目标（例如“30 天内把回撤控制在 5% 以内”），系统按真实组合自动评估。
  8. 做分析：Analytics 看相关性 / 风险；Economy 看宏观周期；Bonds / FX / Commodities 看各自市场深度。
新手上路建议：先把倍速设 X1 慢看一会儿报价怎么动 → 下 1 手体验成交 → 再切 X1000 快进一周，观察新闻和事件如何改变价格。这种“慢看机制、快进结果”的对比，正是这个沙盒最好玩的地方。

7. 交易玩法详解

下单类型

  • 市价单（Market）：以当前实时报价立即成交。注意：若资产不在行情流中（例如刚新建的资产需等下一 tick 注入），会处于 PENDING，价格注入后即成交。
  • 限价单（Limit）：指定目标价，价格到达才成交；未达则挂单等待。

组合与风控

  • 成交后现金、持仓、手续费实时结算，写入数据库，重启不丢。
  • Portfolio 里能看到每只持仓的成本、现价、浮动盈亏；Analytics 看整体波动与回撤。
  • 事件冲击对价格封顶 ±5%，避免单条新闻把市场打爆——这是刻意的全真约束。
练手思路：先用小资金市价单熟悉成交节奏；再用限价单在支撑位“挂钓鱼单”；最后开 Challenges 用真实组合去冲约束目标，比单纯看盘有目标感得多。

8. 数据真实性说明（很重要）

平台有一条不可退化的铁律：禁止用合成数据冒充真实功能。所以界面上每条数据都会标注来源：

标注含义例子
LIVE / REAL来自真实外部源（联网开启时）CNBC 实时价、FRED 宏观、WSJ RSS 头条
SIMULATED本平台按规则合成演化（非真实历史）模拟步进生成的新闻、随机游走出的未来 K 线
FALLBACK真实源不可用时回退的合成数据断网时自动顶上的行情 / 新闻
HISTORICAL历史回放数据种子自带的历史价格序列
怎么辨别你看到的是不是真的？ 开启 USE_EXTERNAL_DATA=True 后，News 页真实头条会显示来源（如 WSJ.com: Markets）和绿色 LIVE 徽标；Economy 的利率会接近真实 FRED 值（如 0.0388）。若只看到 FINANCESIM 来源与灰色 SIMULATED 徽标，说明当前是合成数据。

9. 常见问题与排错

Q1：python / npm 命令找不到？

本机托管运行时里 PATH 默认没有这两个命令。用完整路径即可：

# Python（示例路径，以你本机为准）
C:/Users/Administrator/.workbuddy/binaries/python/versions/3.13.12/python.exe -m uvicorn app.main:app --port 8000
# Node / npm 同理用对应 node.exe 与 npm-cli.js

Q2：前端白屏 / 接口 404？

  • 开发模式：确认前端是 5174、后端是 8000，且 vite 代理正常（/api → localhost:8000，ws:true）。
  • Docker 模式：直接访问 8000 根路径即可，SPA 已由后端托管；不要再去开 5174。

Q3：开了真实数据但新闻还是 “FINANCESIM”？

大概率是没重启后端，或当时网络不通触发了回退。重启后端、确认 backend/.env 的 USE_EXTERNAL_DATA=True，再看启动日志是否出现 “Headlines refreshed from external provider”。

Q4：快进太快，来不及下单？

这是早期版本的已知痛点，已修复：最低倍速 X1 = 1 模拟秒 / 真实秒（实时地板），你可以先停在 X1 慢慢操作，需要时再上调到 X100 / X1000。

Q5：数据会丢吗？重启后还在吗？

交易、组合、现金、快照、事件、宏观历史都落 SQLite，跨重启保留。新建资产也会自动注入行情流，无需重启即可定价 / 交易。

Q6：想完全离线玩？

什么都不用配，默认就是离线优先。所有数据用合成填充，断网照常运行。

10. 实用技巧

  • 慢看 + 快进组合：X1 观察机制，X1000 看长期结果，对比最有意思。
  • 多世界平行宇宙：用 WorldCreator 开不同种子的世界，比较同一策略在不同“运气”下的表现。
  • 快照回放：在关键时点存 Snapshots，事后可恢复重来，做策略对比实验。
  • 看 AI 怎么玩：Bots 页观察四类策略的盈亏，能学到不少市场微观结构直觉。
  • 事件冲击封顶 ±5%：别指望一条新闻暴富或爆仓，这是全真约束，长期看均值回归更靠谱。
  • 来源徽标是底线：做任何判断前先瞄一眼数据是 LIVE 还是 SIMULATED，避免把“沙盒里的随机”当成“真实信号”。
